# 学习版服务范围与模块职责

这是 SupportFlow 本项目的可运行学习版说明，不是某家真实企业的服务承诺。本地知识库只解释随代码维护的项目规则，不包含客户的真实订单数据。

Router/Orchestrator 负责判断问题交给知识检索还是业务工具。RAG 检索本地版本化文档；Agent 编排订单、物流、售后工具；Java 服务负责身份、订单归属、输入、状态和审批权限校验。

订单与物流的具体结果应来自当前店铺下的本人订单查询。售后工具处理本项目的申请和人工判定流程；人工批准后，持久化任务驱动学习版模拟退款，记录进度、金额、模拟凭证与审计。后台支持有限重试和重启恢复，不接支付渠道、不执行真实退款。没有知识或业务记录时，应明确说明不知道或暂无数据。

知识回答由检索到的原文段落抽取整理，并给出 sourceId 与版本。当前没有向量数据库，也不会为知识回答调用外部模型；这是可解释、可离线测试的学习版 RAG。
