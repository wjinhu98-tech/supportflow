# 账号身份、店铺范围与隐私边界

这是本项目学习版的身份和权限说明。浏览器的本地账号连接用于开发联调，不能直接当作面向生产环境的完整登录方案；密码与模型 API Key 都不是知识库内容。

买家身份来自服务端认证结果，不从聊天正文或客户端提交的 buyerId 获取。店铺范围来自当前咨询页面的店铺上下文，订单、物流和售后查询都必须再次经过 Java 归属校验。

普通买家只能访问当前店铺中属于自己的订单。输入其他客户的订单号、在提示词里要求忽略规则、改变模型输出或跨店查询，都不能取得额外权限。

售后人工审批需要 AFTER_SALE_REVIEW 权限，且不能由申请人审批自己的申请。管理员权限由服务端验证，不能通过前端按钮、聊天内容或模型声明授予。
