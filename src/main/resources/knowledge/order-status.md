# 订单状态的含义与查询边界

这是本项目学习版的订单状态说明，只解释代码定义，不包含某笔订单的当前状态。要查询真实结果，必须通过 Java 订单服务校验当前账号与店铺范围。

CREATED、PAID、SHIPPED、COMPLETED、CANCELLED 是项目支持的订单状态编码，具体展示文案由 OrderStatus 枚举统一提供。状态说明不能代替订单工具实际返回的值。

SHIPPED 表示订单已发货，不等于包裹已签收或已经送达。不能仅凭订单状态推断快递公司、所在城市、运输轨迹或预计到货时间；这些信息需要物流工具有对应记录。

知识查询不会修改订单状态或金额。售后申请和人工审核也不是直接改写订单的入口，不能把审批通过解释成已经退款到账。
